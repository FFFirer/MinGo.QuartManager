## Why

前端开发时，前端页面通过 API 地址直接请求后端接口存在跨域问题，且开发环境与生产环境的 API 地址需要手动切换。通过配置开发服务器代理，前端可以请求同源地址，代理服务器自动转发请求到后端开发服务器，简化开发流程并避免跨域问题。

## What Changes

- 配置前端开发服务器的代理功能，将 `/api` 等接口请求代理到后端开发服务器
- 前端代码中 API 地址改为相对路径或前端地址，无需硬编码后端地址
- 开发环境下自动启用代理，生产环境保持原有配置
- 支持热模块替换期间代理配置生效

## Capabilities

### New Capabilities
- `dev-server-proxy`: 配置前端开发服务器代理，实现开发环境下 API 请求自动转发到后端开发服务器

### Modified Capabilities
- (none)

## Impact

- 前端项目开发服务器配置（Vite/Webpack/DevServer）
- 前端 API 请求地址配置
- 后端开发服务器端口配置
